1. HTML Öğrenmek

HTML, web sitelerinin temel yapısını oluşturan işaretleme dilidir. Bir web sayfasındaki başlıklar, paragraflar, resimler ve bağlantılar HTML ile oluşturulur.

Önemli HTML Etiketleri:
  • <h1> : Başlık oluşturur.
  • <p> : Paragraf oluşturur.
  • <img> : Resim ekler.
  • <a> : Bağlantı oluşturur.
  • <ul> : Liste oluşturur.

2. CSS ile Sayfa Güzelleştirme

CSS, HTML ile oluşturulan web sayfalarının görünümünü düzenler. Renk, yazı tipi, arka plan, boyut ve konum gibi özellikleri değiştirmemizi sağlar.

CSS ile neler yapabiliriz?
  • Yazıların rengini değiştirebiliriz.
  • Sayfaya arka plan rengi ekleyebiliriz.
  • Yazı tipini ve boyutunu ayarlayabiliriz.
  • Resimlerin boyutlarını değiştirebiliriz.
  • Sayfanın düzenini güzelleştirebiliriz.

3. Margin ve Padding Arasındaki Fark

Margin ve Padding, CSS ile sayfa düzenlerken kullandığımız iki önemli özelliktir.

Margin Nedir?

Margin, bir HTML öğesinin dışındaki boşluktur. Öğeler arasında mesafe bırakmak için kullanılır.

Padding Nedir?

Padding, bir HTML öğesinin içindeki boşluktur. İçerik ile kenarlık arasında mesafe oluşturur.

Kısaca Aralarındaki Fark

Margin Padding
Dış boşluktur. İç boşluktur.
Öğeler arasındaki mesafeyi ayarlar. İçerik ile kenarlık arasındaki mesafeyi ayarlar.
